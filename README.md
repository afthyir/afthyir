## About

I'm **Afthy Irshath**, known online as **Afthyir**. I'm a full-stack developer and cybersecurity student interested in building useful web applications and understanding the systems that keep software and infrastructure running.

I build with JavaScript, TypeScript, React, Next.js and Node.js, and use Python for scripting and backend work. I style interfaces with Tailwind CSS and work with data and backend services including MongoDB, Redis and Supabase. I deploy projects using platforms such as Vercel and Railway.

Alongside development, I'm learning networking, Linux and security fundamentals. My approach is to consider security throughout the development process—not treat it as an afterthought.
